# 小学数学口算批改器

## 用途

自动批改小学 1-3 年级数学口算题，给出逐题对错、总分和正确率。适合老师快速批改学生作业。

## 触发条件

当用户提到以下关键词时使用本 skill：
- 批改口算
- 口算批改
- 数学批改
- 检查口算题
- 口算作业

## 使用方法

1. 用户提供口算题（图片拍照 或 文本）
2. 逐题计算正确答案
3. 对比学生答案，标注 ✓ 或 ✗
4. 统计总分和正确率

## 输入格式

**文本输入**（推荐）：
```
3+5=8
12-4=8
6×7=42
24÷6=5
```

**图片输入**：
- 清晰的口算题拍照
- 每行一道题

## 输出格式

逐题批改结果：

| 题号 | 题目 | 学生答案 | 正确答案 | 结果 |
|------|------|----------|----------|------|
| 1 | 3+5 | 8 | 8 | ✓ |
| 2 | 12-4 | 8 | 8 | ✓ |
| 3 | 6×7 | 42 | 42 | ✓ |
| 4 | 24÷6 | 5 | 4 | ✗ |

**统计**：共 4 题，正确 3 题，正确率 75%，得分 75 分。

## 注意事项

- 仅适用于 1-3 年级整数四则运算
- 乘法用 × 或 *，除法用 ÷ 或 /
- 如果图片模糊，请用户重新拍照或手动输入
